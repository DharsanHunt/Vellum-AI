# SIDTD & AIForge-Doc Dataset Documentation

## 1. SIDTD (Synthetic Identity Document Tampering Dataset)
- **Official URL**: https://github.com/ComputerVisionCentre/SIDTD
- **License**: CC BY-NC 4.0
- **Size**: ~2.8 GB
- **Samples**: 4,800 ID documents with 12 distinct tampering operations (splicing, text swap, face swapping).
- **Target Directory**: `/data/raw/sidtd/`

## 2. AIForge-Doc (Generative AI Document Forgery Benchmark)
- **Official URL**: https://github.com/AIForge-Doc/Benchmark
- **License**: CC BY-SA 4.0
- **Size**: ~1.5 GB
- **Samples**: 8,500 documents featuring diffusion inpainting and LLM text generation artifacts.
- **Target Directory**: `/data/raw/aiforge/`
