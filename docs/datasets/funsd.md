# FUNSD (Form Understanding in Noisy Scanned Documents) Documentation

## 1. Overview & Purpose
FUNSD is a benchmark dataset for spatial form understanding, key-value extraction, and OCR bounding-box entity recognition.

## 2. Dataset Metadata
- **Official URL**: https://guillaumejaume.github.io/FUNSD/
- **License**: Non-Commercial Research Use
- **Size**: ~35 MB (ZIP archive)
- **Samples**: 199 fully annotated scanned forms (149 train, 50 test), 31,485 word tokens, 9,707 semantic entities.
- **Labels**: Semantic categories (`header`, `question`, `answer`, `other`), linking relationships, bounding boxes.
